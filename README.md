# tg_bot

Telegram-бот на Kotlin, который работает поверх существующего backend API.

## Переменные окружения

- `TG_BOT_TOKEN` — токен Telegram-бота
- `TG_SUPER_KEY` — тот же super key, что используется backend
- `TG_BOT_API_BASE_URL` — базовый URL backend API, по умолчанию `http://backend:8080`
- `TG_BOT_DATA_DIR` — каталог для хранения сессий, по умолчанию `data`

## UX

- `/start` открывает главное меню
- вход и регистрация идут через кнопки
- номер телефона запрашивается через Telegram contact keyboard
- после входа все сценарии сайта доступны через inline-кнопки и пошаговые сообщения

Покрытие функциональности:

- пользователь: профиль, устройства, генерация конфигов, скачивание `.conf`, получение QR
- администратор: пользователи, серверы, все сохранённые конфиги

Для прерывания текущего пошагового сценария можно отправить `/cancel`.
